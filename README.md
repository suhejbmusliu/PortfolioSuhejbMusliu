# Suhejb Musliu — portfolio (2026, early version)

A one-page developer portfolio in plain HTML and CSS. No JavaScript, no
build step.

The newer CV website lives in the `portfoliosm` repository.

---

## What's inside

- Side menu styled as a "command palette" with links to every section, and
  a skip-to-content link
- Hero
- About
- Skills: frontend, backend, database, DevOps & tools
- Projects: QendraERA, Keramika DOO website, AOD (Art of Difference),
  Btecho IT services
- Services: web applications, UI/UX development, API & integration
- Experience and education timeline
- Contact form and GitHub / LinkedIn links

The contact form has `action="#"`, so it doesn't send anything.

---

## Files

| File | What |
|---|---|
| `index.html` | All content |
| `style.css` | All styles |

Icons come from Font Awesome 6 (cdnjs).

---

## Run locally

Open `index.html` in a browser.

---

## Editing content

Everything is in `index.html`. Projects are the `project-title` blocks in
the `#projects` section; skills are grouped by `category-title` in
`#skills`.

---

## Deployment

Any static host works (GitHub Pages, Netlify, Vercel): upload the two
files.
